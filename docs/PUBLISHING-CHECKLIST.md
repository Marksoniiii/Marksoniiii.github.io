# 发布检查清单

这份清单用于重要文章或自动检查无法判断的内容质量。

## 发布前

- 标题准确、摘要能独立说明文章内容。
- `draft` 已关闭，`pubDatetime` 包含正确时区。
- 标签精简且没有含义相同的重复写法。
- 图片已经压缩，Alt 文本描述了图片信息而不是文件名。
- 引用、外链和代码示例经过人工核对。
- 文章涉及隐私、密钥、位置或个人信息时已经脱敏。
- 本地执行过 `npm run build`，或 Pages CMS 的“检查文章”已经通过。

## 发布后

- GitHub Actions 的 `Build and deploy` 已成功。
- 文章 URL、首页文章卡片、标签页与 RSS 均能访问。
- 移动端标题、图片、代码块没有横向溢出。
- 如构建失败，先保留线上版本，修复后重新运行；不要绕过内容检查。

## 回滚

在 `Build and deploy` 的手动运行表单中填入上一个正常版本的 Commit SHA。回滚只是重新部署
历史版本，不改写 Git 历史。问题修复后再部署 `main`。
